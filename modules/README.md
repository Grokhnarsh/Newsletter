# Eigene Module

Jeder Unterordner mit einer `index.js` wird beim Start als Modul geladen.
Ein vollständiges Beispiel liegt in `examples/modules/hinweisbanner/` –
zum Ausprobieren einfach hierher kopieren und den Server neu starten.

Aufbau und Erweiterungspunkte sind in der README im Projektordner beschrieben.
